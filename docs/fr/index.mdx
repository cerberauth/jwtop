## Démarrage rapide

```sh
# Installation
go install github.com/cerberauth/jwtop@latest

# Décoder un token
jwtop decode $TOKEN

# Vérifier avec un secret HMAC
jwtop verify $TOKEN --secret mysecret

# Tester un serveur pour des vulnérabilités JWT
jwtop crack $TOKEN --url https://api.example.com/protected
```
