Les JSON Web Tokens (JWT) sont un standard très répandu pour représenter des claims entre deux parties. Cependant, une implémentation incorrecte de la vérification des JWT peut entraîner plusieurs vulnérabilités de sécurité critiques.

JWTop fournit des outils intégrés pour tester ces vulnérabilités automatiquement ou manuellement.

## Comment tester

Le moyen le plus rapide de tester un serveur en direct contre toutes ces vulnérabilités en une fois est d'utiliser la commande `crack` :

```bash
jwtop crack $TOKEN --url https://api.example.com/protected
```

Pour plus de détails sur chaque vulnérabilité, cliquez sur les cartes ci-dessus.
