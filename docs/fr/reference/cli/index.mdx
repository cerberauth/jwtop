Toute commande acceptant un argument `<token>` peut aussi le recevoir via stdin lorsque l'argument est omis, ce qui permet de chaîner les commandes : `jwtop find --file page.html | jwtop decode`.

## Utilisation globale

```sh
jwtop <command> [flags]
jwtop --help
jwtop version
```

Toutes les commandes retournent `0` en cas de succès et `1` en cas d'erreur. Un échec de vérification retourne également `1`.

## Options globales

| Option | Description |
|---|---|
| `--sqa-opt-out` | Désactive les statistiques d'usage anonymes et les rapports de plantage |
